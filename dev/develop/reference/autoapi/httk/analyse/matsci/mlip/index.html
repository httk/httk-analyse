httk.analyse.matsci.mlip.energy_errors(reference, predicted, *, atom_counts, offset_per_atom=None, weighting='configuration')[source]¶

Compare total energies and report per-atom prediction residuals.

Raw residuals are always reported. An explicit offset is subtracted from each predicted energy per atom; no energy shift is inferred from the data. Mean and RMS statistics weight each configuration equally by default. Choose weighting="atom" to weight each atom equally instead. The reported 95th percentile is unweighted under either policy.

Parameters:

  • reference (collections.abc.Sequence[float]) – Reference total energies in eV.

  • predicted (collections.abc.Sequence[float]) – Predicted total energies in eV.

  • atom_counts (collections.abc.Sequence[int]) – Positive integer atom count for each configuration.

  • offset_per_atom (float | None) – Optional explicit energy offset in eV/atom to subtract from each prediction.

  • weighting (Literal['configuration', 'atom']) – Weight configurations equally or weight each atom equally in means and RMS.

Returns:

Immutable raw and optionally corrected per-atom residual summaries.

Raises:

ValueError – If inputs have incompatible shapes, invalid counts, non-finite values, or unrepresentable residuals.

Return type:

EnergyErrors

httk.analyse.matsci.mlip.force_errors(reference, predicted, *, species, weighting='atom')[source]¶

Compare paired ragged force arrays in eV/angstrom.

Atom order and species labels must identify the same physical atoms in each reference/prediction pair. This array API cannot detect atom permutations or dataset leakage. atom weights every atom equally; configuration gives each configuration equal total weight. Species summaries condition and renormalize those same weights on atoms of that species. The 95th percentile remains unweighted in every summary. The pooled per-component RMSE common in the literature equals rms_vector_error / sqrt(3) of the result with weighting="atom"; rms_vector_error is the Euclidean vector RMSE and is not directly comparable to it.

Parameters:

  • reference (collections.abc.Sequence[collections.abc.Sequence[collections.abc.Sequence[float]]]) – One finite (atoms, 3) force array per configuration.

  • predicted (collections.abc.Sequence[collections.abc.Sequence[collections.abc.Sequence[float]]]) – Matching predicted force arrays in eV/angstrom.

  • species (collections.abc.Sequence[collections.abc.Sequence[str]]) – One chemical-symbol label per atom in matching atom order.

  • weighting (Literal['atom', 'configuration']) – Weight every atom equally or every configuration equally.

Returns:

Immutable component, vector, configuration, and species metrics.

Raises:

ValueError – If shapes, species labels, weighting, or finite numeric values are invalid.

Return type:

ForceErrors

httk.analyse.matsci.mlip.stress_errors(reference, predicted)[source]¶

Compare symmetric tensile-positive stress tensors in GPa.

Tensor pairs are compared without symmetrizing. Components use the order xx, yy, zz, yz, xz, xy and take the upper-triangle value for each shear component. The symmetry check permits absolute or relative differences up to 1e-12; convert virials and source sign conventions before calling. Typical float32 model outputs and virial (-sum(r (x) F)) stresses carry asymmetry of order 1e-8 GPa and are rejected: inspect the asymmetry and symmetrize explicitly ((S + S.T)/2) first. Aggregate component metrics weight each configuration equally. The 95th percentile is unweighted in every summary.

Parameters:

  • reference (collections.abc.Sequence[collections.abc.Sequence[collections.abc.Sequence[float]]]) – Finite stress tensors with shape (configurations, 3, 3).

  • predicted (collections.abc.Sequence[collections.abc.Sequence[collections.abc.Sequence[float]]]) – Matching predicted stress tensors in GPa.

Returns:

Immutable six-component residuals and statistics.

Raises:

ValueError – If shapes, symmetry, or finite numeric values are invalid.

Return type:

StressErrors
