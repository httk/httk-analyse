Immutable lag times, tensor values and time-origin counts.

Tensor units follow kind: angstrom² for msd, (angstrom/ps)² for vacf and angstrom²/ps for vacf_integral.

  • remove_mean – Whether per-atom temporal means were removed (VACF and its integral), else None.

httk.analyse.matsci.dynamics.mean_squared_displacement(unwrapped_positions, timestep, *, max_lag=None, remove_com=False, masses=None)[source]¶

Average displacement outer products over every time origin and atom.

Positions must use persistent atom order and one fixed laboratory/material frame. Wrapped coordinates and changing-cell frame transformations must be resolved upstream. Masses are required for optional center-of-mass removal.

Parameters:

  • unwrapped_positions (Any) – Finite Cartesian array (frames, atoms, 3), in angstrom.

  • timestep (float) – Uniform positive time between frames in ps.

  • max_lag (int | None) – Largest lag, inclusive; default frames minus one.

  • remove_com (bool) – Subtract each frame’s mass-weighted center before displacements.

  • masses (collections.abc.Sequence[float] | None) – Positive atom masses, required only when removing COM motion.

Returns:

Symmetric MSD tensors in angstrom² on lag times in ps, with time-origin counts.

Raises:

ValueError – If data, lag, masses or derived quantities are invalid.

Return type:

TensorSeries

httk.analyse.matsci.dynamics.velocity_autocorrelation(velocities, timestep, *, max_lag=None, remove_mean=False)[source]¶

Compute dimensionful velocity correlation tensors over all origins.

C_ij(k)=mean[v_i(t)*v_j(t+k)] over origins and atoms. The lagged tensor need not be symmetric. This pair-count estimator is not a power spectral density.

Removing each atom’s own time mean also removes Δr/T, the diffusive signal. It biases the integral estimate of D low by about t_plateau/T and drives the full-length integral to zero, so use remove_mean=True only for non-diffusive (solid) systems.

Parameters:

  • velocities (Any) – Array (frames, atoms, 3) in angstrom/ps.

  • timestep (float) – Uniform frame spacing in ps.

  • max_lag (int | None) – Largest inclusive lag.

  • remove_mean (bool) – Subtract each atom/component time mean before correlation; only for non-diffusive systems.

Returns:

Correlation tensors in (angstrom/ps)² on lag times in ps.

Raises:

ValueError – If data, lag or results are invalid.

Return type:

TensorSeries

httk.analyse.matsci.dynamics.van_hove_distinct(positions, timestep, *, lag, bins, cell)[source]¶

Compute the bulk distinct van Hove density with persistent atom identity.

Counts displacements from atom i at each origin to atom j at the lag, with i != j. Minimum images use one fixed periodic 3D cell. The integral over a complete spatial domain is N-1; a finite spherical range is not renormalized.

Parameters:

  • positions (Any) – Cartesian array (frames, atoms, 3) in angstrom, with persistent atom order.

  • timestep (float) – Uniform frame spacing in ps.

  • lag (int) – Nonnegative integer lag.

  • bins (collections.abc.Sequence[float]) – Increasing nonnegative radial edges, within the unique-image radius.

  • cell (Any) – Fixed fully periodic 3x3 row-vector cell in angstrom.

Returns:

Distinct neighbor density per angstrom³, directed counts and center-origin count.

Raises:

ValueError – If data, cell or radial range is invalid.

Return type:

RadialDynamics

httk.analyse.matsci.dynamics.intermediate_scattering(positions, timestep, wavevectors, *, kind, max_lag=None)[source]¶

Compute self or coherent scattering with exp(+i q·displacement).

Self scattering averages over atoms and origins. Coherent scattering is mean[conj(rho(q,t))*rho(q,t+lag)]/N, retaining the density peak at q=0. For arbitrary q use unwrapped positions; periodic wrapped coordinates are phase equivalent only for wavevectors commensurate with the fixed cell.

Parameters:

  • positions (Any) – Cartesian array (frames, atoms, 3) in angstrom.

  • timestep (float) – Uniform frame spacing in ps.

  • wavevectors (Any) – Finite Cartesian (wavevectors, 3) array in inverse angstrom.

  • kind (Literal['self', 'coherent']) – Explicit self or coherent definition.

  • max_lag (int | None) – Largest inclusive lag.

Returns:

Complex correlations in lag and wavevector order.

Raises:

ValueError – If shapes, kind or numeric values are invalid.

Return type:

ScatteringSeries

httk.analyse.matsci.dynamics.velocity_spectrum(velocities, timestep, *, window='hann', remove_mean=False)[source]¶

Compute a one-sided periodogram whose discrete integral obeys Parseval.

This is a velocity power spectrum, not a normalized phonon density of states. It averages equally over atoms and Cartesian components. Multiplying power by frequency spacing and summing gives the window-weighted mean square.

The default keeps each atom’s time-averaged velocity. For a diffusing atom that mean is Δr/T, the diffusive signal: removing it zeroes the rectangular-window ω=0 bin, which is proportional to the diffusion coefficient. Per-atom mean removal is appropriate only for non-diffusive (solid) systems.

Parameters:

  • velocities (Any) – Array (frames, atoms, 3) in angstrom/ps.

  • timestep (float) – Uniform positive frame spacing in ps.

  • window (Literal['none', 'hann']) – Rectangular (none) or Hann window.

  • remove_mean (bool) – Remove each atom/component time mean before windowing; only for non-diffusive systems.

Returns:

THz frequencies and dimensionful velocity power density.

Raises:

ValueError – If input, window or spectral values are invalid.

Return type:

VelocitySpectrum
